# Trae使用说明 - 学术论文写作助手

## 一、简介

这是一个专门为Trae IDE设计的学术论文写作助手Skill，帮助学生完成课程论文、调研报告等学术写作任务。

**核心功能**：
- 任务拆解：把大任务拆成小任务，避免AI幻觉
- 文献驱动：基于文献构建内容，不是凭空生成
- 降低AI率：删除AI高频词汇，增加人味表达
- 格式排版：按照学校规范设置格式

---

## 二、安装方法

### 方法1：复制到项目目录（推荐）

1. **找到你的项目目录**
   - 打开Trae，打开你的论文项目
   - 项目目录通常是你的论文文件夹

2. **复制skill文件夹**
   - 将整个 `academic-paper-writer` 文件夹复制到项目的 `.trae/skills/` 目录
   - 最终路径：`你的项目/.trae/skills/academic-paper-writer/`

3. **验证安装**
   - 在Trae中打开聊天窗口
   - 输入 "帮我写论文" 或 "学术写作"
   - 如果skill被自动识别，说明安装成功

**目录结构示例**：
```
我的论文项目/
├── .trae/
│   └── skills/
│       └── academic-paper-writer/
│           ├── SKILL.md
│           ├── Trae使用说明.md
│           ├── templates/
│           └── examples/
├── docs/
├── output/
└── ...
```

### 方法2：复制到全局目录

1. **找到全局skill目录**
   - Windows: `%userprofile%\.trae\skills\`
   - macOS/Linux: `~/.trae/skills/`

2. **复制skill文件夹**
   - 将整个 `academic-paper-writer` 文件夹复制到全局skill目录
   - 最终路径：`%userprofile%\.trae\skills\academic-paper-writer\`

3. **验证安装**
   - 重启Trae
   - 在任意项目中都可以使用这个skill

**适用场景**：
- 多个项目都需要使用这个skill
- 不想每个项目都复制一遍

### 方法3：通过Trae界面导入

1. **打开Trae设置**
   - 点击右上角Settings图标
   - 选择 "Skills & Commands"

2. **导入skill**
   - 点击 "Import" 按钮
   - 选择包含SKILL.md的文件夹或.zip文件
   - 确认导入

3. **验证安装**
   - 在skill列表中查看是否导入成功
   - 在聊天中测试是否可以使用

## 三、配置Rules（可选）

Rules可以在每次聊天时自动加载，确保AI遵守约束。

### 创建项目Rules

1. **打开项目设置**
   - 在Trae中打开你的项目
   - 进入 Settings > Rules

2. **创建规则**
   - 点击 "+ Create"，选择 "Project"
   - 输入规则名称：`academic-paper-constraints`

3. **设置应用模式**
   - 选择 "Always Apply"（每次聊天都生效）

4. **输入规则内容**

复制以下内容：

```markdown
---
alwaysApply: true
---

# 学术论文写作约束

## 重要约束

当用户要求写论文、课程论文、调研报告时，你必须遵守以下约束：

### 1. 必须先分析需求再执行
**绝对不能直接开始写论文！** 你必须先：
- 分析论文需求（字数、格式、参考文献数量等）
- 拆分任务生成任务清单
- 与用户确认任务清单后才能开始执行

### 2. 每一步都要与用户确认
**不能自作主张把任务全做了！** 你必须：
- 每完成一个步骤都要与用户确认
- 等待用户确认后才能进行下一步
- 如果用户不满意，需要根据反馈修改

### 3. 执行流程（严格遵守）
```
第一步：分析需求 → 输出需求分析 → 等待用户确认
第二步：拆分任务 → 输出任务清单 → 等待用户确认
第三步：执行任务 → 每步完成 → 等待用户确认
第四步：质量检查 → 输出检查结果 → 等待用户确认
```

### 4. 禁止行为
- ❌ 直接开始写论文，不分析需求
- ❌ 一次性完成所有任务，不与用户确认
- ❌ 自作主张决定论文结构和内容
- ❌ 跳过任务清单直接执行

### 5. 必须行为
- ✅ 先分析需求，输出需求分析
- ✅ 拆分任务，生成任务清单
- ✅ 每步执行后与用户确认
- ✅ 根据用户反馈调整
```

5. **保存规则**
   - 点击 "Save" 保存

### 验证Rules

1. **打开新聊天**
   - 在Trae中打开新的聊天窗口

2. **测试约束**
   - 输入 "帮我写一篇课程论文"
   - 观察AI是否先分析需求，而不是直接开始写

3. **检查规则加载**
   - 查看聊天输入框左上角是否显示规则名称
   - 如果显示，说明规则已加载

## 四、使用方法

### 方法1：自动调用（推荐）

1. **描述你的需求**
   ```
   帮我写一篇关于数字孪生在智能制造中应用的课程论文
   ```

2. **AI会自动识别**
   - Trae会自动识别这是学术写作任务
   - 自动加载academic-paper-writer skill
   - 按照skill中的流程执行

3. **按照提示操作**
   - AI会先分析需求
   - 然后拆分任务生成清单
   - 每一步都会与你确认

### 方法2：手动调用

1. **在聊天中指定skill**
   ```
   使用academic-paper-writer skill帮我写论文
   ```

2. **或者使用@符号**
   ```
   @academic-paper-writer 帮我写一篇课程论文
   ```

### 方法3：使用#Rule引用

如果配置了Rules，可以手动引用：

```
#Rule 帮我写一篇课程论文
```

这会强制加载规则，确保AI遵守约束。

## 六、常见问题

### Q1：AI没有自动加载skill怎么办？

**解决方案**：
1. 手动调用：输入 "使用academic-paper-writer skill"
2. 使用@符号：输入 "@academic-paper-writer"
3. 检查skill是否正确安装到 `.trae/skills/` 目录

### Q2：AI直接开始写论文，没有分析需求怎么办？

**解决方案**：
1. 使用#Rule引用：输入 "#Rule 帮我写论文"
2. 明确要求：输入 "请先分析需求，再拆分任务"
3. 检查Rules是否配置正确

### Q3：AI一次性完成所有任务，没有确认怎么办？

**解决方案**：
1. 中断AI：点击停止按钮
2. 明确要求：输入 "请一步一步执行，每步都要与我确认"
3. 使用#Rule引用：输入 "#Rule 请一步一步执行"

### Q4：如何修改AI生成的内容？

**解决方案**：
1. 直接告诉AI：输入 "请修改XXX部分"
2. 具体说明：输入 "请把XXX改成XXX"
3. 重新生成：输入 "请重新撰写XXX章节"

### Q5：如何补充更多文献？

**解决方案**：
1. 告诉AI：输入 "请补充更多文献"
2. 指定方向：输入 "请补充关于XXX的文献"
3. 提供链接：输入 "请使用这个文献：[链接]"

### Q6：如何降低AI率？

**解决方案**：
1. 告诉AI：输入 "请降低AI率"
2. 使用skill：输入 "使用降AI率功能"
3. 手动优化：输入 "请删除AI高频词汇，增加人味表达"

## 七、高级用法

### 1. 自定义Rules

你可以根据需要修改Rules内容：

```markdown
---
alwaysApply: true
---

# 自定义约束

## 格式要求
- 一级标题：黑体 小二（18pt）居中
- 二级标题：黑体 四号（14pt）左对齐
- 正文：宋体 小四（12pt）首行缩进2字符

## 降AI率要求
- 删除以下AI词汇：关键使能技术、重要驱动力、系统梳理
- 使用第一人称：我认为、我觉得
- 变化句子长度
```

### 2. 创建自定义Agent

1. **打开Trae**
   - 在聊天输入框中输入 "@"
   - 点击 "Create Agent"

2. **配置Agent**
   - 名称：学术论文写作助手
   - Prompt：复制SKILL.md中的Instructions部分
   - 工具：Read、Edit、Terminal、Web Search

3. **使用Agent**
   - 在聊天中输入 "@学术论文写作助手"
   - 描述你的需求

### 3. 使用Slash Commands

Trae支持斜杠命令，可以快速调用功能：

```
/paper 帮我写一篇课程论文
/literature 搜索数字孪生相关文献
/reduce-ai 降低这段内容的AI率
```

## 八、注意事项

1. **每步确认**：不要让AI一次性完成所有任务
2. **先看任务清单**：确认任务拆分合理后再执行
3. **及时反馈**：如果不满意要立即提出
4. **检查文献**：确保每段都有文献支撑
5. **降低AI率**：删除AI词汇，增加人味表达
6. **格式规范**：严格按照要求设置格式
