## 五、引用格式模板

### 中文期刊
```
[序号] 作者.标题[J].期刊名，年份，卷(期)：页码.
```

### 中文专著
```
[序号] 作者.书名[M].出版地：出版社，年份：页码.
```

### 英文期刊
```
[序号] AUTHOR.Title[J].Journal,Year,Vol(No):Pages.
```

### 行业报告
```
[序号] 机构.报告名称[R].出版地：机构，年份.
```

### 学位论文
```
[序号] 作者.论文题目[D].城市：学校，年份.
```

### 示例
```
[1] 陶飞, 刘蔚然, 张萌等.数字孪生五维模型及十大领域应用[J].计算机集成制造系统, 2018, 24(1):1-18.
[2] Sooria M, Arezoo B, Dastres R. Digital twin for smart manufacturing, A review[J]. Sustainable Manufacturing and Service Economics, 2023, 2:100017.
[3] McKinsey & Company. Digital twins: The next frontier of factory optimization[R]. New York: McKinsey & Company, 2024.
```

## 注意事项

1. **文献编号**：按顺序编号，便于引用和管理
2. **重要性评级**：用星级表示，便于筛选
3. **内容概述**：简要概括，便于快速了解
4. **关键要点**：提炼核心，便于引用
5. **章节对应**：明确用途，便于写作时查找
6. **获取状态**：记录进度，确保完整性
